# Quercy Propreté — application terrain (v3)

Pointage horodaté par le serveur, contrôle qualité par pièce, photos, signature
client, bon d'intervention, facturation, avis clients, alertes et pilotage.
Fonctionne hors réseau.

- `index.html` — l'application
- `netlify/functions/api.mjs` — le serveur (fichier assemblé)
- `netlify/functions/alertes.mjs` — les alertes automatiques, lancées par Netlify
  toutes les dix minutes (fichier assemblé)
- `NOTICE.md` — la marche à suivre
- `LIAISON-SITE.md` — relier le formulaire de devis du site à l'application

Rien à configurer : tout se règle à la première ouverture.
